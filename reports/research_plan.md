# 研究计划（阶段 1 产出）

日期：2026-08-14 ｜ 数据审计结论见 `data_audit.md`，来源清单见 `references/sources.md`

## 1. 研究问题

在公开 Tox21 qHTS 数据（12 个核受体/应激反应终点）上，建立一套**来源可溯、协议合理、结果可复现**的多终点毒性预测流程：给定分子结构（SMILES），为 12 个终点分别给出活性概率，并量化各终点与整体性能、误差结构与适用范围。目标不是刷高单一指标，而是可验证的研究流程与代码库。

## 2. 数据决定

**采用 MoleculeNet/DeepChem 托管的 Tox21 CSV（7,831×12，SHA-256 固定）为建模数据。**

理由：(a) 审计已证明其与 2014 挑战赛原始训练库逐分子一致（零标签冲突）；(b) 是社区标准基准口径（TDC 同源），结果可与文献定性对照；(c) 文件稳定、校验和可固定。原始挑战赛 SDF 保留作为溯源与交叉验证证据，不用于建模（2,952 个批次级重复组需要自定去重规则，会把研究变成"另一个数据版本"）。

**建模前处理**（固定）：剔除 8 个不可解析 SMILES；其余 7,823 个分子保留原样（混合物/带电/含金属均保留）。剩余 4 行重复结构保留。

## 3. 评价协议

- **主协议：scaffold 分割 80/10/10**（逐行复刻 DeepChem `ScaffoldSplitter`，已单元测试）。动机：与 DeepChem 对该数据文件的默认一致；估计对新颖骨架的泛化——毒理学筛选的实际需求；审计显示该分割干净（泄漏仅 1 例）。
- **敏感性分析：random 分割 × 3 种子**（仅对最终选定模型），量化分割方式对结论的影响（MoleculeNet 论文对 Tox21 用的是 random split，P2）。
- **指标**：每终点 **ROC-AUC**（主）+ **PR-AUC**、**balanced accuracy**（辅，不平衡场景）；整体为 12 终点宏平均。依据：P1（挑战赛主指标）、P2（MoleculeNet 分类指标）、活性率 2.9–16.2% 的现实。
- **边界纪律**：模型/超参选择只看 valid；test 在冻结后只跑一次；random-split 敏感性分析在 test 报告之后进行且不回溯改模型（顺序上属于结论稳健性验证，非选择依据）。

## 4. 建模路线（阶段 2）

分子表示统一用 **Morgan/ECFP4，2048 bit**（半径 2）为主特征；这是该基准上文献最强的经典基线特征（P2 及后续文献），可复现且无外部依赖。不预测 superiority，按以下顺序实验，每步以 valid 宏平均 ROC-AUC 与多种子稳定性决定去留：

1. **Baseline（必须）**：每终点逻辑回归（ECFP4，class_weight balanced）。简单、可解释、确定性强，作为性能下界与流程正确性标尺。
2. **非线性单任务**：每终点 LightGBM（ECFP4；少量超参网格）。
3. **多任务共享表示**：12 终点共享隐层的 MLP（ECFP4 输入；PyTorch CPU；3 种子）。检验多终点迁移是否在该数据上有增益。
4. （可选）MACCS keys 交叉验证特征敏感性；或按误差分析结论决定是否引入图模型。图模型（GNN）仅当 1–3 的误差分析显示指纹表示是明确瓶颈时才引入——需研究动机而非复杂度偏好。

类别不平衡处理：class_weight/损失加权（与 DeepChem 默认 balancing 一致的思路），阈值策略不参与选择（只报排序指标为主）。

## 5. 已识别风险与不确定性

| 风险 | 缓解 |
|---|---|
| 小活性数终点（valid ≤32 活性）指标方差大 | 多种子（≥3）报告均值±标准差 |
| SR-ARE valid/test 活性率漂移（15%→22–25%） | 终点级解读时注明；不作阈值调参 |
| scaffold 分割本身有方差（分组贪心、无随机性，但换数据版本即变） | 固定 CSV 校验和 + 确定性分割算法（复刻已测试） |
| 与文献数字不可直接比（协议不同） | 报告中显式标注协议；同协议内自比 |
| CPU 训练时间 | 数据仅 7.8k×2048 维，全部实验可在分钟级完成 |

## 6. 阶段 3 冻结清单（预定）

固定预处理与模型超参 → 保存模型与配置 → 锁定随机种子 → 跑 test 一次 → 产出 `results/final/` 与最终研究报告 → 记录 Git commit。此后不再依据 test 结果修改模型。
